## Q5's first false positive from a repo whose product is templates

The prescribed escape grep returned hits in this repo:

```
skills/init-project-fastapi/references/tests-scaffolding.md:393  DROP SCHEMA public CASCADE
skills/init-project-fastapi/assets/alembic-env.py:57             create_async_engine(get_url())
```

None of them is this repo's suite. All are inside a skill's **template for other projects**
— the scaffolding `init-project-fastapi` emits. There is no `conftest.py` anywhere in

**In a repo whose product is templates, every hazard grep hits its own documentation of the
hazard.** The same applies to the shared-fixture-escape grep and to any Step 5 sweep for a
dangerous construct. Read the *path* before reading the match — and note this is the
inverse of the 2026-08-13 observo lesson, where zero hits was ambiguous. Here a confident
hit was, too.

## Budget margins are a conflict class no file grep can show

The organising constraint of this plan was not file overlap. Eleven of fourteen items had a
sole owning file — the backlog was near-fully disjoint. What actually shaped it was that
**six files sat within one edit of a token gate**:

| file | binding margin |
|---|---|
| `AGENTS.md` | **28 exact** / 6,000 |
| `init-project-fastapi/SKILL.md` | **43 exact** / 17,100 |
| `orchestrating-issue-backlog/SKILL.md` | **149 estimate** / 23,110 |
| `curating-context/SKILL.md` | **177 exact** / 7,600 |
| `references/process-log.md` | **389 estimate** / 10,000 |
| `init-socraticode/SKILL.md` | **412 exact** / 10,050 |

Two agents editing a file with 43 tokens of headroom conflict even in **disjoint sections**,
and no line-window analysis reveals it — the second to merge simply turns the gate red. The
plan's rule became **one writer per budget-tight file**, which satisfies "foundation shared
files are read-only" by construction rather than by declaration.

Generalization: Step 7's read-only rule currently keys on *"one file every agent's
verification depends on."* The measured criterion is sharper — **a file whose remaining
budget is smaller than one agent's plausible edit is single-writer regardless of section
disjointness.** Measure the gate-bound files at Step 5 and assign owners, the same way
contested files get owners.

## Verify the *option you are about to choose*, not only the issue's claims

Step 4's decide-then-rescore says to surface an issue's unresolved decision at the approval
gate. This session found the next step: **the option chosen at that gate can itself be
infeasible, and the gate is where that has to be caught.**

#190 offered three ways to make the exact token gate visible. The user chose *"print the
exact margin in the offline failure message."* Writing the brief, I checked the mechanism —
`.skills/context-token-counts` holds **four anchored paths, `AGENTS.md` and `docs/` only,
zero coverage of any `skills/*/SKILL.md`.** There is no exact figure available offline to
print. That absence is *why* the estimator runs 13.4% low on the file with no correction.

The intent survived by another route: `POLICY_ESTIMATE_BAND` already exists and
`test_skill_self_budget.py:567` already uses it, so the message can print the **band-derived
worst case** — a quotable number, no API call. Reported as a correction rather than
implemented silently.

**Rule: after the gate picks an option, grep the mechanism it assumes before writing it into
a brief.** An orchestrator's decision is exactly as falsifiable as an issue body's claim,
and it arrives with more authority because the user endorsed it.

## The blast-radius grep is as falsifiable as the hedge grep

2026-08-12's lesson was that an orchestrator's quick regex over an *issue's hedge* is
falsifiable. Same failure, different instrument: I sized #183+#197's blast as **High** from
`grep -rn process-log`, which returned `test_relative_links.py:242,252,367`,
`test_content_invariants.py:1668`, `test_references.py:18-25`.

Every one of those is a **`tmp_path` fixture or a docstring**. Not one is an assertion about
the real file. Blast was Medium, and the only real constraint was that `references/**/*.md`
is globbed recursively, so a new file must be reachable from the index.

**A blast-radius count is a claim about consequences and needs the same treatment as any
other claim: read what the hits are, not how many there are.** Cheap here — five files.

deliverable.
