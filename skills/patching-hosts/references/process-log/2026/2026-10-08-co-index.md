## Session 2026-10-08 — co-index

The third run under the scripts, and this host's first (#313 step 8b; CannObserv/index#9). It hosts the cohort's shared code-search store: Qdrant and Ollama in Docker, under systemd units, bound to the tailnet address only. Nothing on a production path depends on it, and an outage degrades search to `grep`. It was also the host's maintenance-lane catch-up.

### What the skill got wrong or lacked

- **No knob line names a Qdrant data store** (#367). The Iron Law's recovery point went unenforced, and a snapshot left inside a `--rm` container is lost at the next restart.
- **The restarter scan doesn't read the script an `Exec` line runs** (#368), and it reported the list as complete.

### Decisions

- **Snapshot, though the store's stated restore path is a re-index.** The re-index was never timed, and it's expensive.
- **The `inflight` gate reads the access log**, with a marker request so it fails closed.
- **Tailscale is `follow` plus a `hold`, as on replicator.** The services bind its address but order only `After=` it.
- **The run used a one-off window line, removed after.** The probe ran mid-afternoon, outside the drafted night windows.

### Surprises

- The in-flight gate did real work: clients indexed through most of the afternoon, and it held each step until they paused.
- A third host's bulk ran more than twice its dry run.
