### Decisions

- **`notifier_test` is captured, not excepted.** It's 8 MB, and an exception would have needed renewing every time it expired.
- **The callers weren't told,** by the owner's choice. Their failure handlers had sent 6 dispatches since May. Afterwards, the service's own table held none from the hours of the run.
- **The run used a one-off window line, removed after**, as on co-index. The owner chose to run on Friday afternoon rather than wait for the committed Tue/Wed window.
- **Tailscale's pin file and auto-update were fixed before the probe**, so the probe ran against the remedied state.

### Surprises
